01 / THE PRODUCT

Evidence stays with the person who owns the device.

Many Android security apps immediately email an intruder selfie or synchronize the evidence to a cloud account. Lock Witness uses a different model: record it privately on-device, preserve the capture metadata, and let the owner decide when to export or share it.

Its evidence package can be inspected by someone else without access to the application: image/video files, a tabular history, JSON details and a SHA-256 manifest are delivered together.

The tradeoff is clear: this design does not provide the remote recovery and automatic alert functions of theft-tracking competitors.

02 / ENGINEERING PROOF

Six disciplines in one shipping mobile product.

01 / ANDROID

System event handling

Device Admin failed-password callback, explicit activation, active monitoring controls and a camera foreground service.

02 / CAPTURE

Camera and location

Camera2 photo/video, permission checks, capture timeout/failure handling and last-known Android LocationManager snapshots.

03 / PERSISTENCE

Incident data

Room records with timestamp, attempt count, device information, module settings and media-specific outcome statuses.

04 / INTEGRITY

SHA-256 file checks

Stored hashes for captured photo/video, exposed in incident detail and bundled in a portable evidence ZIP manifest.

05 / DELIVERY

Offline evidence transfer

Local ZIP creation with media, CSV, JSON and hashes; explicit Android chooser, never an automatic silent upload.

06 / PRODUCT

Full Android lifecycle

Compose screens, DataStore, diagnostics, Play Billing, release configurations and historical hardware/unit-test evidence.
